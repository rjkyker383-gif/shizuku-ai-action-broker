# Initial Action Allow-list

Allowed prototype actions:

- GET_DEVICE_INFO
- GET_PACKAGE_LIST
- GET_CURRENT_APP
- OPEN_APP
- OPEN_SETTINGS
- GET_BATTERY_INFO
- GET_DISPLAY_INFO

Rules:

- No arbitrary AI-generated shell strings
- No silent microphone or camera capture
- No credential harvesting
- No hidden surveillance
- No destructive commands
- No execution without validation
